# 我的衣橱 · 电子穿搭管家 👔

> 一个简洁、高功能性的个人衣橱管理应用，帮你记录每一件衣服的穿着频次，计算真实性价比。

![Version](https://img.shields.io/badge/version-1.0.9-brightgreen)
![Node](https://img.shields.io/badge/node-%3E%3D18-blue)
![License](https://img.shields.io/badge/license-MIT-orange)

## ✨ 核心功能

### 📦 衣物管理
- 衣物全生命周期管理：添加、编辑、删除、软删除
- 详细属性：名称、分类、季节、颜色、价格、品牌、材质、购买日期、备注
- **场合标签**：工作/休闲/正式/运动/约会/居家/旅行，衣橱页可按场合筛选
- **衣物状态管理**：正常/种草/闲置/丢弃四种状态，详情页一键循环切换
- 照片上传（自动压缩优化）
- **✨ AI抠图+变平整**：随手拍的衣物照片（穿在身上/摆在地上），一键AI抠除背景，自动裁剪+主轴旋转校正变平整，纯前端运行无需API key
- 分类筛选 + 季节筛选 + 场合筛选 + 状态筛选 + 关键词搜索
- 多种排序：最新添加、穿得最多、价格高低

### 📅 穿搭日历
- 日历视图记录每天穿了什么
- 支持多选衣物组合
- 记录天气和穿搭感受
- 点击任意日期查看/编辑当天穿搭

### 🎲 智能搭配
- 一键生成穿搭方案（上衣+裤子+鞋子+配饰）
- **天气联动推荐**：根据温度和天气状况智能推荐最适合的衣物
  - 温度滑块（-10°C ~ 40°C）+ 天气状况选择（晴/多云/阴/雨/雪）
  - 六档温度分类，17种材质保暖性匹配，季节-温度权重算法
  - 雨天优先防水材质，晴天优先防晒配饰
  - 穿搭适配度评分（0-100%）+ 智能穿搭建议
- **颜色搭配评分**：基于色彩理论（HSL色相分析）自动评估搭配和谐度
- 支持40+中文颜色名识别，中性色自动判定为百搭
- 满意后直接记录为当天穿搭
- **⭐ 收藏搭配**：喜欢的穿搭一键收藏到搭配库，随时复用

### ⭐ 收藏搭配库
- 新增第6个主视图"收藏"，管理所有收藏的穿搭方案
- 搭配页生成喜欢的穿搭后点击"收藏这套"，自定义命名保存
- 收藏卡片展示：搭配名称、衣物件数、总价值、衣物缩略图
- 一键"今日穿这套"：自动记录为今日穿搭并累加穿着次数
- 支持删除收藏搭配

### 📊 数据统计与性价比分析
- **总览看板**：衣服总数、穿搭记录、累计穿次、平均单次成本
- **分类分布**：各类衣物数量占比
- **季节分布**：春夏秋冬衣物分布
- **穿着频率 Top 10**：哪些衣服穿得最多
- **性价比排行**：单次穿着成本最低的衣物（价格 ÷ 穿着次数）
- **待提升衣物**：贵但穿得少的衣服，提醒你多穿或谨慎购买
- **衣物详情页**：单次穿着成本、性价比评级（极佳/优秀/良好/一般/待提升）、穿着历史

### 🛒 购物清单
- 想买的衣服统一管理，不再忘记
- 三级优先级（高/中/低），按重要程度排序
- 预估价格记录，自动汇总预算
- 一键标记已购买/撤销购买，已购买项自动划线
- 全部/待购买/已购买三种筛选视图
- 一键清除所有已购买记录，保持清单清爽

### 📈 月度穿搭报告
- 统计页顶部全宽月度报告卡片，一目了然
- 月份切换器，可查看任意月份的穿搭数据
- 四大核心指标：穿搭天数、总穿次、平均单次成本、新购衣物
- 与上月对比：穿搭天数变化、穿次变化（绿色上升/红色下降）
- 本月最常穿 Top 5 排行
- 每日穿搭趋势柱状图，直观展示一个月的穿搭活跃度

### 📱 PWA  Progressive Web App
- 可安装到手机桌面，像原生APP一样使用
- 支持离线访问（Service Worker 缓存）
- 响应式设计，手机/平板/桌面全适配
- 安全区域适配（iPhone 刘海屏）

### 💾 数据安全
- SQLite 本地数据库，数据完全在你自己的设备上
- 一键导出 JSON 备份
- 软删除机制，防止误删

## 🚀 快速开始

### 环境要求
- Node.js >= 18
- npm >= 8

### 安装与运行

```bash
# 1. 进入项目目录
cd wardrobe

# 2. 安装后端依赖
cd backend
npm install

# 3. 启动服务
npm start
```

启动后访问：
- **应用首页**：http://localhost:3000
- **健康检查**：http://localhost:3000/api/health

### 手机访问（同一WiFi下）
1. 查看电脑IP：`ipconfig`（Windows）或 `ifconfig`（Mac/Linux）
2. 手机浏览器访问 `http://<电脑IP>:3000`
3. 在浏览器菜单选择「添加到主屏幕」，即可像APP一样使用

## 📡 API 接口

### 衣物管理
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/clothing` | 获取衣物列表（支持 category/season/search/sort/tag 参数） |
| GET | `/api/clothing/:id` | 获取衣物详情（含穿着历史） |
| POST | `/api/clothing` | 添加衣物（支持 tags 字段） |
| PUT | `/api/clothing/:id` | 更新衣物（支持 tags 字段） |
| DELETE | `/api/clothing/:id` | 删除衣物（软删除） |
| POST | `/api/clothing/:id/wear` | 记录穿着一次 |
| GET | `/api/clothing/tags/all` | 获取所有标签（含计数） |
| PATCH | `/api/clothing/:id/status` | 快速修改衣物状态（v1.0.8新增） |

### 穿搭记录
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/outfits` | 获取穿搭记录（支持 month 参数） |
| GET | `/api/outfits/date/:date` | 获取指定日期穿搭 |
| POST | `/api/outfits` | 创建/更新穿搭记录 |
| DELETE | `/api/outfits/:id` | 删除穿搭记录 |

| GET | `/api/stats/seasons` | 季节分布 |
| GET | `/api/stats/most-worn` | 穿着频次排行 |
| GET | `/api/stats/best-value` | 性价比排行 |

## 🧮 性价比算法

```
单次穿着成本 = 衣物价格 ÷ 累计穿着次数

性价比评级：
  ¥0-5/次   → 极佳 ★★★★★
  ¥5-15/次  → 优秀 ★★★★
  ¥15-30/次 → 良好 ★★★
  ¥30-60/次 → 一般 ★★
  ¥60+/次   → 待提升 ★
```
